# Triage Labels

This repository uses the default triage label vocabulary.

## Labels

- `needs-triage`
- `needs-info`
- `ready-for-agent`
- `ready-for-human`
- `wontfix`

## Mapping

- `needs-triage` → new or unreviewed work
- `needs-info` → waiting on clarification or missing details
- `ready-for-agent` → ready for implementation by an agent
- `ready-for-human` → needs a human decision or review
- `wontfix` → intentionally not planned
