# Domain Docs

This repository uses a single-context layout.

## Layout

- Root `CONTEXT.md` holds the main project context.
- `docs/adr/` holds architecture decision records.

## Consumer Rules

- Read `CONTEXT.md` first for the active project context.
- Read ADRs when you need design history or architectural decisions.
- Keep `CONTEXT.md` focused on current scope, constraints, and project state.
- Add a new ADR when a decision is durable and worth preserving.
